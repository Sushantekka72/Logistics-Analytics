# 📦 Logistics Analytics Dashboard | Supply Chain KPI Analysis

## 📌 Project Overview

This project presents an interactive **Logistics Analytics Dashboard** built in **Microsoft Excel** to analyze supply chain and transportation performance. The dashboard transforms raw logistics data into meaningful business insights through KPI tracking, interactive visualizations, and operational performance analysis.

The objective of this project is to help logistics managers monitor shipment performance, evaluate carrier efficiency, identify delivery trends, and support data-driven decision-making.

---

## 🎯 Objectives

- Analyze logistics and transportation performance.
- Monitor important Supply Chain KPIs.
- Compare carrier performance.
- Identify shipment and delivery trends.
- Support operational decision-making through interactive dashboards.
